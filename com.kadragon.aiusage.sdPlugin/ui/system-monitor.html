Choose a local Windows metric. GPU metrics use the selected NVIDIA GPU index, which is named on the key when it is not 0. A gauge under the value shows how full the metric is. The CPU and GPU temperatures are shown as a value and also set the background color: green below 60 C, amber from 60 through 79.9 C, and red at 80 C or higher. The CPU key shows the true package temperature while LibreHardwareMonitor or OpenHardwareMonitor is running; otherwise it falls back to the ACPI thermal zone, which is a chassis sensor. Network is shown in Mbps.
